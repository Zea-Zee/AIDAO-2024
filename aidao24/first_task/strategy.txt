Предобработка данных, маппинг парцелляций из атласа в Brainnetome в парцелляции атласа Schaefer200 скриптом map_data.py в папке parc_mapping. Внутри папки также находятся 2 атласа(воксели, разделенные на разные парцелляции) для brainnetome и schaefer200 атласов. На выходе получается файл schaefer200_data.npy.
Поиск кластеров скриптом first_task.py на данных из schaefer200_data.npy.

Суть работы алгоритма:
1) Считаем матрицы функциональной связности для каждого скана по временным рядам.
2) Превращаем каждую матрицу в вектор, следовательно имеем 320 векторов размерности 200х200
3) Прогоняем вектора через Метод Главных Компонент(PCA) для поиска линейных зависимостей
4) Прогоняем уменьшенные векторы после PCA через алгоритм UMAP, для поиска нелинейных зависимостей.
5) Делаем кластеризацию по полученным векторам в сильно сжатом признаковом пространстве(к этому этапу кластеры уже хорошо разделены) алгоритмом Growing Neural Gas
6) Выводим преобразованные данные с помощью предобработки TSNE
Ответы записываются в файл submission.csv
